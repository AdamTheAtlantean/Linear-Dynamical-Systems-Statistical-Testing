# Linear Dynamical Systems: Statistical Testing via VAR Approximation

This repository contains simulation experiments for comparing linear dynamical
systems (LDS) through finite-order vector autoregressive (VAR) approximations.
The project was developed as an internship research codebase and is organized
around a statistical testing question:

> Given two observed time series, can we decide whether they were generated by
> the same underlying LDS or by different LDS realizations?

The experiments simulate LDS observations, fit VAR models to the generated
series, compare the estimated VAR coefficient vectors, and study how well those
distances separate the null hypothesis from the alternative.

## Core Idea

The simulated LDS has the form

$$
x_{t+1} = A x_t + L e_t
$$

$$
y_t     = C x_t + e_t
$$

where `x_t` is the latent state, `y_t` is the observed output, and `e_t` is
observation noise. A central object in the experiments is the effective memory
matrix

$$
F = A - L C
$$

For the observed process, the VAR-style impulse response coefficients are
controlled by powers of this matrix:

$$
\Phi_{i} = C F^{(i-1)} L
$$

Thus, the spectral radius `rho(F)` determines how quickly the VAR coefficients
decay. The newer experiments in this repository sample systems by controlling
`rho(F)` directly, rather than controlling only `rho(A)`. This keeps the
simulation design aligned with the theory behind the VAR approximation.

## Experimental Pipeline

Each experiment follows the same broad pipeline:

1. Sample one or more LDS realizations with a prescribed `rho(F)` regime.
2. Simulate observed time series from those systems.
3. Fit a VAR(`p`) model to each observed series using least squares.
4. Vectorize the estimated VAR coefficient matrices.
5. Compute distances between coefficient vectors.
6. Compare distance distributions under:
   - `H0`: both series are generated by the same LDS.
   - `H1`: the two series are generated by different LDS realizations.
7. Sweep a parameter such as `p`, sample length `T`, state dimension `d_x`,
   observation dimension `d_y`, noise scale, or regime separation.
8. Evaluate threshold-based classification performance using ROC/AUC, F1,
   false positive rate, and false negative rate.

## Repository Layout

```text
Notebooks/
  core_experiment.py      Main single-experiment pipeline and plotting helpers
  lds.py                  LDS simulation utilities
  var_model.py            VAR design matrix construction and least-squares fitting
  sampling_utils.py       Sampling systems with controlled rho(F)
  linalg_utils.py         Linear algebra helpers, including spectral radius
  IR_utils.py             Impulse-response distance utilities
  metrics.py              Isotropic and Mahalanobis-style distance functions
  threshold.py            Threshold sweeps, ROC/AUC, and classification metrics
  evaluate_H0.py          H0-specific false-positive evaluation
  evaluate_H1.py          H1-specific true-positive evaluation

  sweep-p.py              Sweep over VAR order p
  sweep-T.py              Sweep over time-series length / effective sample size
  sweep-dx.py             Sweep over latent state dimension
  sweep-dy.py             Sweep over observation dimension
  sweep-escale.py         Sweep over observation noise scale
  sweep-delta.py          Sweep over separation between rho(F) regimes

mahal_misc/
  Earlier Mahalanobis-distance and exploratory experiment scripts.
```

The most current path is the `rho(F)`-controlled experiment family in
`Notebooks/core_experiment.py` and the `Notebooks/sweep-*.py` scripts.
The `mahal_misc/` folder preserves earlier exploratory scripts.

## Installation

The code is pure Python and relies on standard scientific Python packages.
Python 3.10 or newer is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
pip install numpy scipy matplotlib joblib
```

## Running Experiments

Run the main experiment:

```bash
python Notebooks/core_experiment.py
```

Run a specific sweep:

```bash
python Notebooks/sweep-p.py
python Notebooks/sweep-T.py
python Notebooks/sweep-delta.py
python Notebooks/sweep-dx.py
python Notebooks/sweep-dy.py
python Notebooks/sweep-escale.py
```

The sweep scripts print summary statistics and classification metrics, and many
of them also produce diagnostic plots.

## Key Parameters

- `rho_min`, `rho_max`: target spectral-radius band for `F = A - LC`.
- `p`: VAR order used to approximate the observed LDS process.
- `n`: observed time-series length.
- `d_x`: latent state dimension.
- `d_y`: observation dimension.
- `e_scale`: observation noise scale.
- `realizations`: number of fixed LDS realizations sampled per experiment.
- `trials`: number of Monte Carlo trials per realization.
- `diff_regime_y3`, `diff_regime_y4`: optional alternative regimes for the
  two systems compared under `H1`.

## Interpretation

The output distances are not universal constants. They depend on the simulation
regime, VAR order, sample length, noise level, dimensionality, and random seed.
The threshold analyses should therefore be read as empirical performance
summaries for a given experimental design, not as fixed decision rules that
transfer unchanged to all LDS settings.

The central qualitative question is whether the estimated VAR coefficients
carry enough information to distinguish same-system pairs from different-system
pairs, and how that separability changes as the experiment parameters vary.

## Current Status

This is a research prototype. The conceptual spine of the project is stable:
simulate LDS data, approximate with VAR models, compare coefficient estimates,
and study threshold-based testing behavior. Some older exploratory scripts are
kept for reference, while the newer `rho(F)`-controlled code is the preferred
basis for continued experiments.
